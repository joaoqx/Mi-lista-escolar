# Mi Lista Escolar

Motor web para listas escolares familiares, comparación de tiendas y cotizaciones.

La página index.html es una interfaz preliminar. Para cargar PDF y consultar precios automáticamente necesita un servidor con endpoints /api/extract y /api/prices. GitHub Pages no ejecuta estos servicios.

Nunca colocar claves privadas de proveedores de búsqueda en index.html.
